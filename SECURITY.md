# Security policy

This project is pre-release and has not completed an independent security audit. Only the current main branch is maintained; there are no supported production releases yet. See [known limits](docs/security.md) and [validation results](docs/validation-results.md).

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/IzaanAnwar/location-journal/security/advisories/new) when available. If the repository does not offer that form, contact [the maintainer](https://github.com/IzaanAnwar) to request a private reporting channel before sharing details. Do not publish exploit details in an issue while arranging a private channel.

Include the affected commit, platform, expected and actual behavior, impact, and a minimal reproduction with synthetic records. Never send your real location history, passcode, signing key, or database encryption key. There is no guaranteed response time or bug bounty.

An intact signature does not establish true location, personal presence, trusted time, or a complete history. Report any behavior or wording that suggests otherwise.
